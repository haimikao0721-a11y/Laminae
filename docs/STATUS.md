## 一、七个命令

### 为什么选这几个

- **archify**：Astro 站点 + 大量 `.mjs`，用来验单文件组件和模板里的引用。
- **django 没选**：34072 个主线提交 × 7089 个文件，估算要几十小时。

## 三之二、证据等级：每一块能拿它做什么

报告里的桶不是一样可靠的。同一个页面上，「契约对不上」和「孤立模块」差着一个数量级，
所以每一块都标出等级。**等级不是严重程度，是「这条结论能拿它做什么」。**

| 等级 | 名字 | 能做什么 | 不能做什么 |
|---|---|---|---|
| **A** | 有出处 | 文档或仓库自己写明了这件事，可以当核对结果 | 只能核对外面写了什么，不能替你判断该不该这样写 |
| **B** | 有文本证据 | 仓库某处提到过这个名字，说明有人在按它办事 | 提到名字不等于就是它，同名和举例都算提到 |
| **C** | 只有结构事实 | 陈述一个中性事实：没有别的代码引用它 | **不能推出它没用**。入口、示例、按路径加载的东西天生没有入边 |
| **D** | 看形状推断 | 请人看一眼：函数体空、只返回常量这类形状值得复核 | **不能当缺陷**。设计如此的写法到处都是，这一档整类整类地错过 |

各桶落在哪一级：

| 等级 | 桶 |
|---|---|
| A 有出处 | 入口点（清单、目录角色）、契约（路由声明与调用） |
| B 有文本证据 | 按约定加载、注入线索 |
| C 只有结构事实 | 孤立模块 |
| D 看形状推断 | 往下看一层、需要人工复核、有实质代码但还不能算真实现 |

**这一栏是靠类型强制的**：`BucketEvidence` 的键是桶名的全集，加一个新桶不写等级 `tsc` 就报错。
另有一条测试钉住措辞 —— D 级的「能」里不允许出现「确认」「证明」「确实」「一定」，
C 级的「能」里不允许出现「没用」「可以删」。

## 四、修掉的坑（每条都有前后数字）

### 1. 单文件组件里的引用看不见

**原来** vue 上 170 条孤立，前几轮修到 4 条，剩下那 4 条全是同一个原因：引用它们的是 `.vue` 文件，而 `.vue` 不在代码文件范围内，那条边根本不存在。

**现在** `.vue` / `.svelte` / `.astro` 都算代码文件，解析前只取 `<script>` 块或 `---` 围栏 —— 模板是 HTML，当 JS 解析会把属性里写的东西当成代码。

**vue 170 → 0，archify 64 → 0。**

顺带纠正一句错话：archify 那两个文件我早就写过「真的没人用」，其实是被 `.astro` import 的。**「工具没找到证据」和「证据不存在」不是一回事。**

---

### 2. 「往下看一层」的一整类误报

**原来** vue 上「当前成立」12 条，抽样看基本都是误报。修掉四类之后是 0：

| 类别 | 例子 | 为什么不是缺陷 |
|---|---|---|
| 注释里的代码样例 | `// no: function NODE() {}` | 注释不是代码 |
| 字符串里的代码样例 | `"const xxx = () => {}"` | 字符串不是代码 |
| 类型声明 | `declare function foo(...)` | `.d.ts` 里不可能有实现 |
| 箭头函数 | `export const NO = () => false` | 箭头是表达式，空不空说明不了功能做没做 |

**vue 12 → 0。**

最后一类的边界要写清楚：文件级判定**仍然**用这个信号 —— 一个文件里只有一句常量箭头，`classifyDepth` 照样判 placeholder。那是「这个文件没写什么」，和「这个函数要不要人看」是两件事。

---

### 3. graph 阶段：整条流水线的 79%

**原来** 端到端 1397 秒，graph 一步 1102 秒。

| 指标 | 改变前 | 改变后 |
|---|---|---|
| 每 commit | 212.5 ms | **63.8 ms**（3.3 倍） |
| 端到端 | 1397 秒 | **465 秒** |
| graph 一步 | 1102 秒 | **269 秒**（4.1 倍） |

四轮：换掉回溯正则（1.04 倍）、**增量只处理变了的文件（2.05 倍）**、**6513 次 git 调用换成 2 次（3.10 倍）**、遮罩改切片（3.33 倍）。

**最重要的教训：profile 里的百分比不等于可回收的墙钟时间。** 我盯着占 26.2% 那一行改了三轮只快 4%。真正有效的是把「每个 commit 重扫 5.6 MB」变成「只扫变了的文件」。

---

### 4. 分叉树上的跳数

**原来** 报的是「最后算出来的那条路径」，不是最短的。两处错叠在一起：无条件覆盖，每条调用边只处理一次（后来发现近路也不重算）。

**现在** 取最短路径。分叉树上 `entry→near→base` 是 2 跳，不再报 3。

---

### 5. 命令类事实：分支上也能测

**原来** 分支扫描里对 `test-passes` 这类直接记「测不出来」，注释写着「不是测不出来，是这一版故意不做」。**可用户看到的就是「测不出来」**，注释区分不了这两句话。

**现在** 检出到临时 worktree 真跑，watch 的文件没变就不重跑，跑完删掉，不动主目录。

实测（造的小仓库，main 上命令失败、分支上修好）：

```
功能可用  main=假  分支=真  ← 分支上修好了，没合进来
```

## 五、工具能表达的范围到哪为止

这一节不是待办清单。前面五条都修完了，剩下的这些**不是缺陷，是参照系本身的限制**。

### 1. 文件确实在用，但没有任何文本证据

ElyOffice 上有 6 条孤立，全在 `site/video/` —— 宣传视频的录制脚本，靠人手动跑，本来就不该被 import。

**这是真发现，不是误报。** 一个人看报告，看到「6 个孤立模块都在 `site/video/`」，十秒钟就能判断。工具能做的是**把范围缩到这么小**，不是消灭它。

### 2. 只能看到「现在没人用」，看不到作者意图

一个文件从写下来那天起就没人引用过，和「以前有人用、后来不用了」，在引用图上是同一个样子。工具报的是前者那个事实，不是「该删」。

### 3. 动态构造的路径最多追一层

`` `render-${type}.mjs` `` 这种能认。但 `path.join(a, b, c)` 里三个变量拼出来的路径认不了。认不了就不猜 —— 报出来让人看。

### 4. 语言覆盖

JS/TS（含 JSX、SFC）、Python、Rust 有语法模块。Java、Go、C/C++、Kotlin、Swift、Ruby、PHP 这些扩展名认得出来，但**只说「认得出、没模块」，不判真假**。

### 5. 文档里的事实要写得能被正则匹配

`claims.json` 的 locator 是正则，捕获组里那个数就是文档声称的值。文档换了写法（比如「约 20 个」改成「二十来个」），locator 就匹配不上，记成「测不出来」。**这不是工具判错，是它看不到。**

## 六、这个工具的边界

**它核对，不体检。**

- **核对**：文档说 X，去代码里查 X 是不是真的。这类输出在真实仓库上没出过错。
- **体检**：工具自己觉得哪里有问题，然后报告。这类输出在真实仓库上整类整类地错过。

判断一个功能属于哪一类，看它有没有**出处**：

| | 核对 | 体检 |
|---|---|---|
| 谁提出的 | 文档自己 | 工具 |
| 有没有出处 | 有，指得出哪一行 | 没有，是启发式 |
| 错了谁知道 | 一跑就露 | 没人知道 |

**体检类输出要么取证，要么别以「问题」的形态出现。** 这是这一路最贵的一课，详见 [踩过的坑](LESSONS.md)。
