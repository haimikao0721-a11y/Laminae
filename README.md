# laminae

[中文](README.md) | [English](README.en.md)

**把文档里的一句话，在每个 commit 上验一遍真假。**

不是「现在对不对」，是**这条说法从什么时候开始假的、假了多久、最后是怎么收场的**。

下面全部来自真实仓库 [vuejs/core](https://github.com/vuejs/core)：6513 个主线提交、4 条说法。[打开这份报告](docs/demo/vue-report.html)（单文件，1.8 MB，数据与脚本全部内联，无外部请求）。

## 一、它回答什么

![裁决](docs/demo/01-verdict.png)

中位 hiatus **91 个 commit / 720 小时**：一条说法从变假到被收场，中间隔着 91 个提交。

样本 6 段先真后假，其中 0 段还挂着。4 条说法里 1 条曾经为假，到 HEAD 全部为真。

## 二、每一段假的多长、怎么结束的

![假段](docs/demo/02-runs.png)

不用点开就能看到：从哪个 commit 开始变假、当时文档写的什么、实际是什么、哪个 commit 以什么方式收场、一共挂了多久（`共 69 commit / 720.03 小时`）。

「升级本体 → 文档忘了跟」这种形状一目了然：`3.0.11` 在文档里，清单里找不到；69 个 commit 之后才补上。

## 三、往下看一层

![往下看一层](docs/demo/03-down.png)

说法为真、但指着的文件像空壳时，标出来。**当前成立 0 条；另有 44 条只在历史提交里出现过**，折叠着，不占版面。

## 四、每一块结论能拿它做什么

![证据等级](docs/demo/04-layers.png)

这是整个工具最要紧的一栏。四个等级说的是**这条结论能拿它做什么**，不是严重程度：

| 等级 | 能 | 不能 |
|---|---|---|
| **有出处** | 文档或仓库自己写明了，可以当核对结果 | 只能核对外面写了什么 |
| **有文本证据** | 仓库某处提到过这个名字，有人在按它办事 | 提到名字不等于就是它 |
| **只有结构事实** | 陈述「没有别的代码引用它」 | **不能推出它没用**，入口和示例天生没有入边 |
| **看形状推断** | 请人看一眼那些形状 | **不能当缺陷**，设计如此的写法到处都是 |

这一栏是类型强制的：加一个新的分类不写等级，编译就过不去。

## 跑起来

需要 git，以及能直接跑 `.ts` 的 Node（24.7 上验证过）。目标项目不需要装依赖。

```bash
node <laminae>/scripts/init.ts        # 从文档挑候选，在 HEAD 上核一遍，写出 claims.json
node <laminae>/scripts/run.ts         # 跑完整流水线
```

`init` 只负责**提议和核对**，不判真假。它摆出每条候选捕获到了什么、事实量出什么、是不是还是占位。剩下的那件事留给人：**这句该数什么**。

改完跑一遍，报告落在 `<项目>/.laminae/runs/<id>/laminae.html`。

完整参数、环境变量、输出路径见 [REFERENCE](docs/REFERENCE.md)。

## 结果怎么读

每个 commit 上的状态有四种：

| 值 | 含义 |
|---|---|
| 0 | 真 |
| 1 | 假 |
| 2 | 尚未写入文档（该 commit 上文档里还没有这条说法，不是没做完，也不是假） |
| 3 | 测不出来（文档里有，但该 commit 上测不到对应的事实） |

连续为假的区间叫假段，长度就是 hiatus。每个假段按收场方式归类：现实追上了说法 / 文档追上了现实 / 文档被改正 / 说法被删 / 两边都变了 / 仍挂着。

**中位 hiatus 用 Kaplan-Meier 估计。** 到 HEAD 仍挂着的段按右删失处理——直接取中位数会把它们当成「到此为止」而偏小；删失太多、曲线没降到 50% 时显示「无法估计」。

## 它核对，不体检

| | 核对 | 体检 |
|---|---|---|
| 谁提出的 | 文档自己 | 工具 |
| 有没有出处 | 有，指得出哪一行 | 没有，是启发式 |
| 错了谁知道 | 一跑就露 | 没人知道 |

**判定类输出在真实仓库上没出过错；出错的全是「工具自己觉得这里有问题」这一类**，而且是整类整类地错：click 上 15 个孤立模块 15 条全错，vue 上 170 条孤立里 119 条在 HEAD 上根本不存在。

修完之后 click 孤立 0、vue 孤立 0。**体检类输出要么取证，要么不以「问题」的形态出现。**

## 边界

不是待办清单，是参照系本身的限制。

- **语法逐门手写。** JS/TS（含 SFC）、Python、Rust。Java、Go、C# 只报「认得出、没模块」，**不判真假**。
- **「有实质代码」不是「真的实现了」。** 这一节不执行代码，也不知道公式算得对不对。要碰到函数体里算出来的数，用 `test-passes` / `invariant-holds` / `output-unchanged`。
- **一条说法只捕获一个数。** 「1600–1800」要拆成两条；「1600+」要自己写 `compare: gte`。
- **会执行的命令，跑之前先摊开。** 命令原文、要跑多少次、出处是谁——`claims.json` 若是随仓库来的，不是本机的 git 身份，就不跑。

完整的边界、验证过的仓库、已知问题见 [现状](docs/STATUS.md)、[踩过的坑](docs/LESSONS.md)、[参考](docs/REFERENCE.md)。
